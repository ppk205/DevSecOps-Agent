OS command injection via unsanitized query parameter passed to Process.Start

unresolvedcritical · model-46f74f · CWE-78

Ping() binds an attacker-controlled value from [FromQuery] string host and concatenates it directly into the argument string handed to Process.Start("cmd.exe", "/c ping -n 1 " + host). The value flows from an HTTP query parameter into a shell (cmd.exe /c) with no validation, quoting or escaping, so a payload such as '127.0.0.1 & whoami' or '127.0.0.1 & powershell -enc ...' is executed with the web process identity. No argument list API or allow-list is used, so this is a genuine tainted flow into a command-execution sink.

Insecure BinaryFormatter deserialization of untrusted stream (RCE gadget chain)

unresolvedcritical · model-525828 · CWE-502

Load(Stream body) passes a caller-supplied stream straight into BinaryFormatter.Deserialize with no type restriction, binder, or serialization guard. BinaryFormatter is documented by Microsoft as unsafe and removed in .NET 8+ precisely because deserializing attacker-controlled bytes enables gadget-chain remote code execution and arbitrary object instantiation. The stream has no validation, size limit or trusted-source check, and the method is public on a plain class, making it a reachable deserialization entry point.

SQL injection via string concatenation into SqlCommand query

unresolvedcritical · model-06edaa · CWE-89

Find() takes [FromQuery] string user and builds the query text by concatenation: "SELECT * FROM Users WHERE Name = '" + user + "'". No SqlParameter is added, so a value such as ' OR '1'='1' -- or a UNION payload can alter the executed statement, allowing authentication bypass and full-table data exfiltration. Contrast with SafeSql.cs, which uses the same shape but binds @u through AddWithValue and is therefore not vulnerable.

Stored/reflected XSS via @Html.Raw on unencoded model data

unresolvedhigh · model-66c182 · CWE-79

The view renders Model.Bio with @Html.Raw, which writes the value to the response without HTML encoding. Bio is a user-profile field, so any attacker-supplied content (profile bio, comment, imported data) executes as script in every viewer's browser, enabling session theft and account takeover. SafeView.cshtml renders the same field with the default @Model.Bio encoding and is correctly protected.
