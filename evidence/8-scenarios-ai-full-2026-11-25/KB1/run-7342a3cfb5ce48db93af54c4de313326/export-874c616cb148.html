OS command injection via unvalidated 'host' request parameter

unresolvedcritical · model-0f317f · CWE-78

The 'host' parameter is read straight from HttpServletRequest and concatenated into a string handed to Runtime.getRuntime().exec(). Because the command is wrapped in 'sh -c', shell metacharacters in the parameter (e.g. ';', '|', '$(...)', backticks) are interpreted by the shell, allowing an attacker to execute arbitrary OS commands with the servlet container's privileges. No allow-list, escaping or argument-array form is used.
