OS command injection in Ping via unsanitized 'host' query parameter

unresolvedcritical · model-fbf3e4 · CWE-78

The 'host' query parameter is read straight from the request and concatenated into a string passed to `sh -c`. Shell metacharacters (;, |, $(), backticks) in the value let an unauthenticated attacker run arbitrary commands as the server process.

unresolvedcritical · model-0d4a90 · CWE-89
