unresolvedcritical · model-f21085 · CWE-798

A GitHub PAT is embedded as a preprocessor macro in a shipped header. Anyone with the source (or the compiled binary's string table) can extract the token and gain whatever repository access the token's scopes grant, including pushing code or exfiltrating private repos. Container runs as root with a floating 'latest' base image

unresolvedhigh · model-193a6e · CWE-UNCLASSIFIED

The image never switches to an unprivileged user, so every process in the container runs as UID 0. Combined with 'ubuntu:latest', which is unpinned and mutable, a compromise of any process or a poisoned upstream image yields root inside the container and eases container-escape and host-volume abuse. The hardened sibling image uses a distroless nonroot base with an explicit UID.
